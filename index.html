Branch in AI Chatbot to Avoid Scrolling – Privacy Policy

Last updated: 25 October 2026

Branch in AI Chatbot to Avoid Scrolling is a browser extension that lets you highlight text in a response on gemini.google.com, ask a follow-up question about it, and read the answer in a branch shown under that response. This policy explains what the extension handles and where that information goes. Branch in AI Chatbot to Avoid Scrolling is an independent project and is not affiliated with, endorsed by, or sponsored by Google.

Summary

  • When you submit a branch, the text you highlighted, your question, the full Gemini response it came from, and earlier turns of that branch are sent to the Google Gemini API using your own API key.
  • Your API key and your saved branches are stored locally in your browser.
  • The developer of Branch in AI Chatbot to Avoid Scrolling does not operate any server, and does not collect, receive, or store your data.

Information the extension handles

  • Page content on gemini.google.com. The extension runs on gemini.google.com so it can detect which text you highlight and read the Gemini response that contains it.
  • Your branch questions and answers. The questions you type into branches and the answers returned for them.
  • Your Google AI Studio API key and chosen model name. You enter these on the extension's settings page.
  • Saved branches. For each Gemini conversation, the extension saves the structure of your branches: the highlighted text, your questions, the answers, and which response each branch belongs to.

How the information is used

When you submit a branch, the extension sends the following to the Google Gemini API (generativelanguage.googleapis.com) so that it can generate an answer: the text you highlighted, your question, the full text of the Gemini response the highlight came from, and the earlier questions and answers in the same branch thread. The request is authenticated with the API key you provided. The extension does not use this information for any other purpose.

Where the information goes

The only destination is Google's Gemini API, which processes the request under Google's own terms and privacy practices. Depending on the type of API account you use, Google's terms may allow it to use submitted content to improve its products. Please review Google's Gemini API terms before using the extension with sensitive content. The extension's developer does not receive a copy of any request or response.

Where the information is stored

Your API key, model name, and saved branches are stored in your browser's local extension storage (chrome.storage.local) on your device. Your API key is stored without encryption in your browser profile and is only ever sent to Google as part of your own requests to the Gemini API. The extension does not sync this data to any server operated by its developer.

What the extension does not do

  • It does not run any server that receives your data.
  • It does not use analytics, telemetry, advertising, or tracking.
  • It does not sell or share your data with third parties, other than sending your branch requests to Google's Gemini API as described above.
  • It does not load or execute remotely hosted code.
  • It does not read or modify pages outside gemini.google.com.

Permissions

  • storage – to save your settings and branches locally.
  • Access to gemini.google.com – to detect highlighted text and show branches inside the Gemini page.
  • Access to generativelanguage.googleapis.com – to send branch requests to the Gemini API.

Your choices and control

  • You can delete any branch (and the branches nested under it) with its delete button.
  • You can remove your API key at any time by clearing it on the settings page and saving.
  • Uninstalling the extension removes its locally stored data from your browser.

Limited Use

The use of information received by Branch in AI Chatbot to Avoid Scrolling will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
